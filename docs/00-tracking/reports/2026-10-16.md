## 1. Tóm tắt

- Đánh giá tiến độ: 13/21 UC xong, 5/15 minigame xong, 8 game chờ chơi thử. Chủ dự án yêu cầu làm trước UC-13, 14, 16, 19 với Supabase.
- Mở và duyệt CR-009, viết chi tiết 4 UC trong SRS 1.6, viết ADR 0011 (Supabase, server chấm Kiểm tra não) và ADR 0012 (tải lười chữ).
- Chủ dự án đã chốt:
  - Server chấm điểm Kiểm tra não.
  - Đăng nhập bằng phiên khách ẩn danh hoặc Google.
  - Lịch sử lưu 3 loại.
  - Bảng xếp hạng chung và từng minigame; bảng bạn bè chờ có tính năng kết bạn.
- Đã code xong:
  - Luyện tập.
  - Kiểm tra não (phòng solo `BrainTestRoom`, Điểm Não 0–1000).
  - Tài khoản và lịch sử.
  - Bảng xếp hạng.
  - Migration SQL có RLS và RPC.
  - Luật chấm một câu dùng chung cho cả 3 chế độ: `judgeAnswer`.
- QA PASS, không lỗi S1/S2. `pnpm check` xanh: shared 240, server 54, web 128 test. Còn vướng: chưa có project Supabase thật để kiểm phiên, Google và nút xoá dữ liệu.

## 6. Kiểm thử và chất lượng

- `pnpm check`: xanh. Shared 240/240, server 54/54, web 128/128 test; biome 327 file.
- Build web: JS ban đầu khoảng 248 KB gzip (≤ 300 KB); supabase-js là chunk tải lười.
- SQL chạy trên PGlite (Postgres 17 WASM) có giả lập role Supabase: RLS, quyền, RPC, tuần giờ VN, `rules_version`, xoá dữ liệu đều đúng.
- Chrome headless profile tạm, 390 px và 1280 px, không có Supabase:
  - Luyện tập (khoá 1,5 s, kỷ lục).
  - Kiểm tra não đủ 5 game tới `finished`.
  - Bảng xếp hạng và Tài khoản ở trạng thái chưa kết nối.
  - Party 2 tab: không hồi quy.
  - vi/en, sáng/tối.
- Chưa kiểm được:
  - Supabase thật: phiên khách, `getClaims`, RLS qua PostgREST, quyền xoá `auth.users`.
  - Đăng nhập và liên kết Google.
  - Hẹn giờ 5 phút trên trình duyệt.
  - Thiết bị cảm ứng thật.
